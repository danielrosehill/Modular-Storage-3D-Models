US open-front picking bin 18 x 11 x 10 in
US-PB-30260

A US open-front picking bin, 18 x 11 x 10 in depth x width x height (457 x 279 x
254 mm), modelled on the Akro-Mils AkroBin 30260 from Akro-Mils sheet AKM505. The
AkroBin part-number ladder is the de facto US reference for this family, and
Quantum QUS and Uline sizes match it. The front wall stands at roughly 40% of the
back wall's height with the side walls sweeping down between them on a curve, so
an operator can reach in and pick without lifting the bin off the shelf.

The body is tapered, which lets empty bins nest into one another, and the base
sits on an inset plinth so a loaded bin stacks squarely on the one below. A rolled
lip runs around the front opening.

No dimensional standard governs this family, so sizes are manufacturer-specific.
Note the axis order is depth x width x height, not the length x width x height
used for the crates.

TYPICAL USE
Built as a set-dressing and layout asset for warehouses, stockrooms, workshops and
factory scenes: pick-face and shelf fills, small-parts storage walls, WMS and
inventory-system visualisation, facility and architectural walkthroughs, training
and simulation environments, and product configurators.

Modelled at true real-world scale with clean low-poly topology and a single flat
base colour, so it instances cheaply in a wall of several hundred bins and can be
recoloured without touching the mesh.
